# KanbanDemo

These projects demonstrate the impact of using Blazor skills from [dotnet/skills](https://github.com/dotnet/skills) with GitHub Copilot coding agent.

- **KanbanDemo-Baseline**: A Kanban board built without Blazor skills.
- **KanbanDemo-WithSkill**: The same Kanban board built with Blazor skills enabled, showing improved code generation and adherence to Blazor best practices.
